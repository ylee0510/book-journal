# 付箋（Sticky Notes）機能 設計仕様

Date: 2026-05-25

## 概要

読書カードに「付箋」を貼る機能。気になったページの一節や感想をメモとして残せる。カード右上からしおりタブがはみ出して付箋の存在を示し、カードポップアップを開くと内容が読める。

## データモデル

### Firestoreフィールド追加

`books` コレクションの各ドキュメントに `stickyNotes` 配列を追加する。

```json
{
  "stickyNotes": [
    {
      "id": "abc123",
      "page": 46,
      "text": "苦しみに意味を見つける瞬間。自分に刺さった。",
      "color": "yellow",
      "createdAt": 1716600000000
    }
  ]
}
```

| フィールド | 型 | 必須 | 説明 |
|-----------|---|------|------|
| id | string | ✅ | nanoid で生成するローカルID |
| page | number \| null | ❌ | ページ数（空欄OK） |
| text | string | ✅ | 付箋本文（最大200文字） |
| color | string | ✅ | "yellow" / "pink" / "blue" / "green" の4色 |
| createdAt | number | ✅ | Date.now() |

色はインデックス順に自動割り当て（0→yellow, 1→pink, 2→blue, 3→green、以降ループ）。

## UI仕様

### 1. カード上のしおりタブ（はみ出し表示）

- 付箋が1枚以上ある場合のみ表示
- カード右上から上方向にはみ出す
- 複数枚は高さをずらして重ねる（手前＝最新追加）
- 各タブにページ数を横書きで表示（ページ数なしの場合は「…」）
- タブの色は各付箋の color に対応
- 最大4枚まで表示（5枚以上は4枚目タブに小バッジ「+n」）
- タブクリック → カードポップアップを開く

### 2. カードポップアップ内付箋セクション

既存の「こんな人へ」セクションの下に追加。

**表示（全ユーザー）:**
- セクションヘッダー: `📌 付箋メモ`
- 各付箋を縦に並べる（ページ昇順）
- 付箋1枚の構成: ページ数（灰色小文字） + 本文
- 左端にカラーボーダー（color対応）

**自分のカードの場合の追加機能:**
- 「＋ 付箋を追加」ボタン（破線ボーダー、付箋色）
- タップ → インラインフォームが展開
  - ページ数入力（number, optional, placeholder: "p. ―"）
  - 本文テキストエリア（required, maxlength: 200）
  - 「貼る」ボタン / 「キャンセル」
- 各付箋の右端に `×` 削除ボタン（確認なしで即削除）

### 3. EDIT モーダル内付箋セクション

既存フォームの最下部（「記録する」ボタンの直前）に追加。

- 既存付箋の一覧表示（ページ昇順）
- 各付箋に `×` 削除ボタン
- 「＋ 付箋を追加」ボタン → インラインフォーム（ポップアップと同仕様）
- EDIT保存時（updateDoc）に stickyNotes も一緒に保存

## 操作フロー

### 付箋追加
1. カードポップアップ or EDIT画面で「＋ 付箋を追加」をタップ
2. ページ数（任意）と本文を入力
3. 「貼る」→ `updateDoc` で `stickyNotes` 配列に追記
4. 即座にUI反映（楽観的更新）

### 付箋削除
1. 付箋の `×` をタップ
2. `updateDoc` で該当IDを配列から除去
3. 即座にUI反映

## CSS設計

```css
/* しおりタブ */
.sticky-tab         /* 各タブ */
.sticky-tab--yellow / --pink / --blue / --green  /* 色バリアント */

/* ポップアップ内セクション */
.sticky-section         /* セクション全体 */
.sticky-note            /* 1枚の付箋 */
.sticky-note--yellow / --pink / --blue / --green
.sticky-note__page      /* ページ数 */
.sticky-note__text      /* 本文 */
.sticky-note__delete    /* ×ボタン */

/* 追加フォーム */
.sticky-add-btn         /* ＋ 付箋を追加ボタン */
.sticky-form            /* インラインフォーム */
```

## 実装範囲・制約

- `stickyNotes` は既存の `books` ドキュメントに配列として同居（サブコレクション不使用）
- Firestore 無料枠のドキュメントサイズ上限（1MB）に注意。1付箋あたり最大200文字なので実用上問題なし
- 付箋の追加は `stickyNotes` 配列にオブジェクトを追加し `updateDoc` で保存
- 付箋の削除は ID でフィルタした配列全体を `updateDoc` で上書き保存（`arrayRemove` はオブジェクト完全一致が必要なため不使用）
- 自分のカード（`isMyBook(book)`）のみ追加・削除可能。他人のカードは閲覧のみ
- 既存の `books` リスナー（`onSnapshot`）で自動反映されるため、追加のリスナー不要

## 実装対象外

- 付箋の編集（一度貼ったら変更不可。削除して貼り直す）
- 付箋のプライバシー設定（常に公開）
- 付箋へのいいね・コメント
